## 3. 수치·파일럿 측정법

시작 설정 후보: lite / 요청 640×480·최대30fps / 추론15~20Hz / visibility 0.5 / TTL200ms / cooldown300ms. 최소 속도·재무장 이동량은 첫 합성 검사 후 live 파일럿 전에 설정 버전에 고정한다. 시행 중 값을 바꾸면 이전 회차와 합산하지 않는다. 임계값과 화면 크기는 로그에 남긴다.

| 항목 | 반복·분모 | 후보 기준 / 보고 방법 |
| --- | --- | --- |
| 정상 타격 | 좌/우 각20회, 매 시도 건물 정상 복원·궤적 재무장 | 의도한 통과 중 수락 비율 ≥90%. 손별 성공/20·누락·중복을 별도 집계 |
| 비의도 타격 | 정지10회+화면상 빗나감10회, 매 시도 복원 | 비의도 타격 시도/20 ≤5%. 2D 깊이 한계는 별도 설명 |
| 가림 복구 | 10회, 손목 유실→복구 첫 점→다음 궤적 | 유실/복구 첫 점 타격 0, 재무장 뒤 정상 타격 확인 |
| 중복·종료·복원 | 위 시도 전체+60초3회·재접속3회 | 중복·종료 후 점수 0. 리셋 시 건물/점수/이벤트 초기화 |
| 성능 | 60초3회·20분 실행, 버전·망·모델/경로 고정 | 렌더30fps·유효 입력15Hz·전체 지연 p95≤250ms 후보. 평균/분위수·프레임 폐기·측정 횟수도 보고 |

정상/빗나감의 정답은 화면에서 손목이 목표 영역을 통과했는지로 정의하고 관찰 기록을 남긴다. 건물이 이미 파괴된 상태의 추가 휘두름은 정상 타격 분모에 넣지 않는다. 검출 실패도 정상 시도의 누락으로 센다. 판정 불가능한 관찰은 제외 수·이유를 공개한다. 이는 내부 파일럿이며 기존 D04의 참가자 수·지정/자유 과제 비교 실험을 대체하지 않는다.

PC 내부 지연은 observed_at_pc_ms → infer_start/end → game_accept/render 구간으로 측정한다. 전체 지연은 외부 촬영에서 실제 손 움직임 기준 사건과 PC 피드백을 같은 영상으로 확인하고 표본 수·촬영fps·관측 오차·p50/p95를 적는다. 외부 촬영이 없으면 전체 지연은 미측정으로 둔다. 서로 다른 기기의 wall clock 차이로 추정하지 않는다.
