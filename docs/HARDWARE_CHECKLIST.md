# 실제 장비 확인표

담당 제안: 김태이 측정·배치, 정경호 입력·보정 매핑, 이동수 모니터 확인.

## 장비 목록

| 논리 ID | 실제 기기·OS·브라우저 | 렌즈·해상도·회전 | 연결 방법 | 삼각대 위치 | 보정 ID |
| --- | --- | --- | --- | --- | --- |
| C0 | 미정 | 미정 | 미정 | 정면·모니터 근처 | 미정 |
| C1 | 미정 | 미정 | 미정 | 왼쪽 사선 | 미정 |
| C2 | 미정 | 미정 | 미정 | 오른쪽 사선 | 미정 |

PC CPU/GPU/RAM, 모니터 해상도, 네트워크 종류, 실제 플레이 공간 크기도 기록합니다. 비밀번호·개인 식별 정보는 공개 저장소에 넣지 않습니다.

## 첫 연결

- [ ] 휴대폰 3대에서 카메라 권한과 HTTPS 접속 확인
- [ ] C0/C1/C2를 실제 기기에 표시
- [ ] 동시에 접속하고 중복 ID·교체 연결·재연결 시험
- [ ] 후면/전면 렌즈, 줌·크롭·회전, 가능한 초점·노출 설정 고정
- [ ] 각 카메라에서 한 명의 참가자와 보정 기준물이 보이는지 확인
- [ ] C0 영상이 모니터로 전달되는지 별도 확인
- [ ] 카메라 1대 종료 시 해당 기기만 끊김으로 표시

현재 코드로는 로컬 미리보기까지만 확인할 수 있습니다. 서버 등록·영상 전달 점검은 T01~T03 구현 후 수행합니다.

## 보정

- [ ] 기준물의 실측 길이와 좌표를 기록
- [ ] 다면 마커라면 각 면의 공통 월드 위치·방향을 기록
- [ ] K와 왜곡계수는 렌즈·영상 설정별로 계산
- [ ] R/t는 같은 공통 기준물 위치에서 계산
- [ ] 알려진 점을 다시 투영하고 평균·최대 오차 기록
- [ ] 바닥 큐브가 실제 기준점에 맞는지 C0에서 확인
- [ ] 카메라 이동·렌즈·회전·해상도 변경 후 재보정 규칙 확인

## 연속 동작

추론·영상·렌더링을 함께 실행한 20분은 초기 점검 제안입니다. 초반/중간/끝의 추론 FPS, 모니터 FPS, 전송 지연, 시간차, 발열, 배터리·충전, 프레임 누적을 기록합니다.

- [ ] 잠금·절전·권한 취소·네트워크 끊김 안내
- [ ] 손목 가림과 한 시점만 남는 상황에서 충돌 억제
- [ ] 재연결 첫 프레임의 오타격 없음
- [ ] 몸이 지나갈 동선에 삼각대·케이블·타인이 없음

측정 결과는 `data/local/`에 보관하고, 공유할 때는 개인 정보 없는 요약만 문서에 추가합니다.
