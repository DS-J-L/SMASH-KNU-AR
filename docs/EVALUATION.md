## PPT 기준 실행 초안

- 같은 참가자가 연습, 지정 동작, 자유 동작을 수행합니다.
- 각 60초는 PPT에 제시된 파일럿 후 확정할 제안값입니다.
- 실험 운영은 이동수가 설명·진행, 김태이가 장비·안전·관찰, 정경호가 로그·성능 기록을 맡는 안을 제안합니다.
- 체형이나 동작 차이는 실제로 수집한 변수만 비교합니다. 6명을 대표 표본으로 설명하지 않습니다.
- 설문은 재미·사운드·피로도·종합 경험을 각각 기록합니다. 피로도가 높은 점수의 의미를 문항에 명확히 씁니다.

## PCK를 계산하기 전에

PCK는 정답 허용 범위 안에 들어온 관절의 비율입니다. 아래를 결정하지 않으면 숫자를 계산해도 해석하기 어렵습니다.

1. 2D 픽셀 PCK인지 3D 공간 PCK인지 정합니다. 2D 결과를 3D 정확도로 보고하지 않습니다.
2. 독립적인 정답 좌표를 어떻게 만들지 정합니다. 사람이 표시한 2D 좌표 또는 독립적으로 측정한 3D 기준을 사용하며 시스템 자신의 예측을 정답으로 삼지 않습니다.
3. 허용 오차·정규화 길이·대상 관절·샘플링 시점을 본 실험 전에 고정합니다.
4. 정답 작성이 가능한 샘플을 분모로 정하고, 추적 실패를 숨기지 않습니다. 평가 가능한 샘플에서 예측이 없으면 실패로 세는 규칙과 별도의 추적 성공률을 함께 보고하는 안을 제안합니다. 정답 자체가 불명확한 제외 샘플의 수와 사유도 기록합니다.
5. 정답 작성자, 버전, 익명 세션 ID를 남깁니다. 영상이 필요하면 사전 동의 범위 안에서만 수집합니다.

## 게임과 성능 지표

- 유효 타격 감지율과 비접촉 오타격률을 별도로 측정
- 중복 타격, 추적 불가 시간, 연결 손실, 중단·재시도 기록
- 재투영 오차(px), 실제 위치 오차(cm), 수신 이후 처리 시간(ms), 동작→피드백 전체 지연(ms)을 구분
- 추론 FPS와 렌더 FPS를 따로 기록
- 로그의 수신 이후 처리 시간만으로 전체 반응 지연을 대신하지 않음

## 기록 필드 초안

익명 세션 ID, 실험 버전, `tracking_mode`, `task_type`, 과제 순서, 프레임·관절 ID, 정답 좌표와 단위, 예측 좌표 또는 null, 가시 시점 수, 오차, 타격 이벤트, 참조 판정, 중단·제외 사유를 남깁니다.

원본 영상·참가자 명단·동의서는 공개 저장소에 올리지 않습니다. `data/local/`은 Git에서 제외되어 있습니다. 코드에는 실제 참가자 결과 대신 형식 예시만 둡니다.
