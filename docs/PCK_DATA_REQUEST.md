# PCK 계산용 데이터 저장 요청

- 작성: 김태이 (2026-11-25)
- 받는 사람: 정경호 (서버·로그 담당)
- 관련: 이슈 #27 (사용자 테스트 분석 설계 초안)

## 왜 필요한가

사용자 테스트(12/7, 12/9)는 3대 버전으로 PCK를 측정합니다. 하지만 지금 서버는 PCK에 필요한 데이터를 받기만 하고 저장하지 않아서 계산을 시작할 수 없습니다.

PCK는 이렇게 계산할 계획입니다.

1. 3D 융합 관절을 C0 보정값(K, R, t)으로 C0 사진에 재투영합니다.
2. 같은 시각의 C0 사진에 사람이 관절 13개를 직접 표시합니다(정답).
3. 두 점의 거리가 몸통 길이(왼어깨~오른골반)의 0.2배 이내면 맞은 것으로 셉니다.

그래서 **같은 시각의 C0 사진, 융합 관절, C0 보정값**이 세트로 남아 있어야 합니다.

## 지금 상태 (main `4f4e126` 기준)

대상 경로는 `/test/multi3d/`입니다. PR #24(카메라 3대 접촉점 연쇄 폭파)가 이 경로를 씁니다.

| 데이터 | 서버에 들어오나 | 저장되나 | 위치 |
|---|---|---|---|
| C0 사진 (폭 360px, 약 4장/초) | 들어옴 | 카메라마다 마지막 1장만 메모리에 두고 덮어씀 | `backend/test_multi3d.py` `hub.jpegs[camera]` |
| 융합 관절 | 서버가 계산함 | 화면으로 보내기만 함 | `multi3d_fused` |
| C0 보정값 | 들어옴 | 메모리에만 있음 | `hub.calibs`, `hub.calib_msgs` |

`docs/MULTI3D_TEST.md`에도 "저장은 하지 않는다"로 적혀 있습니다.

> 사용자 테스트를 `/test/multi3d/`가 아니라 `?mode=wide`나 2대 무대(`?mode=duo`)로 진행할 계획이면 알려 주세요. 그 경로 기준으로 요청을 다시 정리하겠습니다.

## 요청 사항

### 1. 저장 켜기/끄기

- 기본은 꺼 둡니다. 테스트할 때만 켭니다(설정값이나 PC 화면 버튼 등 방식은 편하신 대로).
- 저장 위치는 이미 `.gitignore`에 있는 `data/local/` 아래로 해 주세요.

### 2. 세션 폴더 구조 (제안)

```text
data/local/pck/<session_id>/
  meta.json          세션 ID, 시작·종료 시각, 참가자 코드(P1~P6, 이름 X)
  calib/C0.json      C0 보정값(K, R, t, 이미지 크기, dist). 바뀔 때마다 시각과 함께 새로 기록
  frames/C0/<server_ms>.jpg   C0 사진 (지금 받는 360px 그대로)
  frames.jsonl       사진 한 장당 한 줄: camera, file, t_ms(폰 시각), server_ms
  fused.jsonl        multi3d_fused 한 번당 한 줄: input_reference_ms, cameras_used,
                     joints(13개: p, cams, err_px), reasons
```

- C1, C2 사진은 선택입니다. 정답 표시는 C0만 씁니다.
- 형식이나 이름은 서버 구조에 맞게 바꾸셔도 됩니다. 아래 "꼭 필요한 것"만 지켜지면 됩니다.

### 3. 꼭 필요한 것

- [ ] **사진과 관절을 같은 시계로 맞출 수 있어야 합니다.** 사진의 `t_ms`는 폰 시각이고(`phone.js`에서 `multi3d_frame`의 `input_at_ms`와 같은 `latest.t`), `input_reference_ms`는 서버 기준 시각입니다. `multi3d_jpeg`에는 `clock_id`가 없으니, 그 카메라의 현재 시계로 프레임과 같은 `clock.to_server(...)` 변환을 해서 서버 시각을 사진에도 같이 남겨 주세요.
- [ ] 보정값이 테스트 중에 바뀌면, 바뀐 시각과 새 값이 남아야 합니다.
- [ ] 저장 때문에 게임 판정이 느려지면 안 됩니다. 쓰기는 큐나 별도 스레드로 처리해 주세요.

### 4. 있으면 좋은 것

- 과제 구분 표시(연습 / 실험 A / 실험 B 시작·종료). 없으면 관찰 기록지 시각으로 맞추겠습니다.

## 용량 추정

C0 사진 한 장을 약 20KB로 잡으면 1명당 180초 × 4장 = 720장(약 14MB), 6명이면 약 86MB입니다.

## 개인정보

- 사진에 참가자 얼굴이 찍힙니다. `data/local/`에만 두고 커밋하지 않습니다.
- 참가자 이름 대신 P1~P6 코드만 씁니다.
- 분석이 끝나면 동의서에 적은 기간에 맞춰 삭제합니다.

## 일정

- 파일럿(11/27~30) 전에 저장이 되면, 파일럿에서 PCK 계산 과정을 끝까지 한 번 돌려 볼 수 있습니다.
- 저장이 되면 정답 표시와 PCK 계산 스크립트는 제가 맡겠습니다.

## 완료 기준

- [ ] 저장을 켜고 3대로 1분 테스트하면 위 폴더에 사진, 관절, 보정값이 쌓인다.
- [ ] 사진 한 장을 골랐을 때 가장 가까운 `fused` 줄을 서버 시각으로 찾을 수 있다.
- [ ] 저장을 꺼 두면 지금과 똑같이 동작한다.
