# 2대 무대 — 4초 콤보·점수·PC 플레이 HUD

2026-11-27, Asia/Seoul. 부분 파괴·80% 교체를 유지한 실제 구현이다. [설계 이력](COMBO_SCORING_PLAN.md)·[데이터 계약](DATA_CONTRACT.md)·[장비 연결](DUO_STAGE_TEST.md)을 함께 본다. 자동 검증과 실제 폰 인수는 구분한다.

## 실행과 규칙

1. 이 작업 폴더에서 [README](../README.md) 절차대로 서버를 실행하고 PC에서 `/test/building/?mode=duo&key=<접속키>`를 새로 연다. 판정 폰 C0/C1과 화면 V를 기존대로 연결한다.
2. **슈퍼 연출을 끈 일반 부분 파괴**에서 PC의 V 영상에 총점·콤보·배율·4초 게이지·철거 수가 표시된다. 일반 보기와 전체화면 모두 표시한다. 폰에 게임 HUD를 추가하지 않는다.
3. 새 파편을 부순 첫 타격은 ×1.0, 직전 실제 break부터4초 이하의 다음 타격은 ×1.1, ×1.2…다. 한 휘두르기(swing_id)의 후속 파편은 같은 배율로 합산하고 마지막 새 파편 제거 시각으로 시간을 갱신한다. 현재 swing 구분은400ms 공백 기반이며 실제 제스처 인식기가 아니다.
4. `타격 점수 = 새 고유 파편 수 × [1+0.1×(연속 타격 번호-1)]`. 내부는0.1점 단위 정수다. 원래 건물별 파편1점 `score`와 파괴 범위는 유지한다. 예: 파편10개씩 세 별도 행동이면10+11+12=33점이다.
5. 자동 다음 건물이 켜져 있으면80%(`ceil(N×0.8)`)부터 서버가 다음 목록 대상을 확정한다. PC들은 같은 epoch의 전환을 중복 요청해도 한 번만 바뀐다. duo 일반 모드의 비율은80%로 고정한다. 기존 별도3초 대기를 더하지 않고 다음 모델 준비로 넘어가며, mono/wide·슈퍼의 기존 교체 설정은 유지한다. 현재 건물을 진행하는 동안 다음 충돌 데이터와 PC 모델을 한 대상씩 선준비하고, 실제 교체 때 재사용한다. 준비용 모델로 현재 파괴/점수/epoch를 바꾸지 않으며 사용하지 않는 PC 선준비 자원은 해제한다.
6. 새 모델/충돌체가 PC에 준비됐다고 ACK하기 전에는 몸 타격을 차단한다. 최초 유효 ACK에서2초 무적을 시작하고 그중 앞1초만 콤보 시계를 멈춘다. 로딩 동안 이미 흐른 시간은 돌려주지 않는다. 이미 만료된 콤보는 되살리지 않는다. 반복 ACK는 무적/정지 시간을 늘리지 않는다.
7. 무적 앞1초는 `콤보 잠시 정지`와 고정 게이지, 다음1초는 무적이 남아 있어도 게이지가 다시 감소한다. UI는 서버 snapshot을 보간할 뿐 점수·만료를 확정하지 않는다.
8. 헛스윙·빈자리·중복 이벤트·재밀기·나중에 떨어지는 파편만으로 콤보가 오르지 않는다. 마우스/시험용 직접 제거는 새 몸 타격 점수를 만들지 않는다. `live/synthetic/replay` 출처가 바뀌면 점수 기록을 분리해 새 기록으로 시작한다.
9. 자동 교체와 PC 새로고침/재접속은 점수를 유지한다. `점수 초기화·다시 세우기`/기존 건물 복원·수동 장면 변경·모델을 재생성하는 설정 변경·모드 변경은 새 점수 기록으로 시작한다. 점수는 서버 메모리 범위이며 서버 재시작 시 초기화된다.

이번 구현은 duo의 콤보/점수/HUD·전환 연결이다. 기존 별도 video_check/phone_2d 세션은 바꾸지 않았다. duo의60초 종료/결과 화면·외부 랭킹은 별도 한 판 기능이며 이 HUD의 `걸린 시간`은 현재 건물의 경과 시간이다.
