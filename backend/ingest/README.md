# 입력 수신 · T01~T03

주 담당 정경호, 휴대폰 담당 김태이. 다음 파일은 구현할 때 추가합니다.

- `registry.py`: C0/C1/C2와 실제 device_id, 중복 접속 거부, 재연결·끊김 상태
- `schemas.py`: `pose_2d` 필드 검증, 크기 제한, NaN·잘못된 좌표 거부
- `pose_receiver.py`: 최신 관측 큐, 서버 수신 시각, 프레임 역전·중복 검사
- `video.py`: C0 영상 경로. 관절 메시지의 큐와 분리
- `pc_capture.py`: D01에서 PC 추론을 채택할 경우에만 추가

현재 카메라 등록·관절 수신은 구현되어 있지 않습니다. [데이터 계약](../../docs/DATA_CONTRACT.md)을 먼저 맞춥니다.
