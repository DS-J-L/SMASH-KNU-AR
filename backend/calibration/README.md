# 카메라 보정 · T05

정경호 계산, 김태이 촬영·배치, 이동수 모니터 정합 검증.

| 파일 | 상태 | 내용 |
| --- | --- | --- |
| `storage.py` | 구현 | 보정 파일 읽기·검증(형태, 유한값, 회전행렬, 월드 기준), 프레임과의 일치 검사(보정 ID·기기·해상도·회전), 정규 좌표 변환 |
| `intrinsics.py` | 미구현 | 기기별 K·dist와 영상 설정, 재투영 오차 |
| `extrinsics.py` | 미구현 | 공통 기준물에서 World→Camera의 R·t |

파일 형식은 [calib/README.md](../../calib/README.md)에 있습니다. 다면 마커는 면마다 별도의 원점을 그대로 사용하면 안 됩니다. 실측한 면→공통 기준물 변환이 필요합니다. 윤곽 가이드는 설치 보조이며 수치 보정을 대체하지 않습니다.

`source`가 `measured`인 파일만 보정 준비 상태를 true로 만듭니다. `synthetic`은 소프트웨어 시험용입니다.
