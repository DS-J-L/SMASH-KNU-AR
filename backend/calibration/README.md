# 카메라 보정 · T05

정경호 계산, 김태이 촬영·배치, 이동수 모니터 정합 검증.

- `intrinsics.py`: 기기별 K·dist와 영상 설정, 재투영 오차
- `extrinsics.py`: 공통 기준물에서 World→Camera의 R·t
- `storage.py`: 실제 보정 파일과 기기·렌즈·해상도·회전 일치 검증

위 파일은 예정 목록입니다. 현재 보정 코드는 없습니다. 다면 마커는 면마다 별도의 원점을 그대로 사용하면 안 됩니다. 실측한 면→공통 기준물 변환이 필요합니다. 윤곽 가이드는 설치 보조이며 수치 보정을 대체하지 않습니다.

결과는 `calib/local/`에 저장하고 실제 보정 완료 전 게임 준비 상태를 false로 유지합니다.
