# 시계 보정과 프레임 정렬 · T06

정경호 구현, 김태이 실기기 검증. `clock.py`에 기기별 오프셋·RTT·불확실성, `frame_aligner.py`에 최신 버퍼·허용 시간차·수명 검사를 구현할 예정입니다.

폰별 performance.now()는 그대로 비교할 수 없습니다. 촬영 메타데이터와 영상 재생·추론 시작·서버 수신 시각도 구분합니다. 공통 광원이나 보드 동작으로 상대 지연을 확인합니다. 추정 시각은 그 출처와 한계를 로그에 남깁니다.

초기 설정 45ms는 파일럿으로 조정할 허용 시간차 제안입니다. 실제 동기화 성능 보장이 아닙니다. 현재 정렬 알고리즘은 없습니다.
