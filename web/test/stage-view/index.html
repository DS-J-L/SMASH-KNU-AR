사람 윤곽 대기

WebRTC는 폰 → PC로 바로 보내고(서버는 연결 신호만 중계), 사람 윤곽은 PC가 받은 영상에서 계산합니다. 연결이 안 되면 자동으로 JPEG로 보냅니다. 아래 장/초·가로·윤곽 설정은 JPEG 방식에만 씁니다.

윤곽을 영상보다 드물게 보내면 폰이 덜 무겁지만, 빠르게 움직일 때 가림이 조금 늦게 따라옵니다. 실제 장/초가 고른 값보다 낮거나 `전송 밀림`이 보이면 와이파이가 못 버티는 것이니 영상 가로·장/초를 낮추세요(밀린 장면은 쌓지 않고 건너뜀).

서버 연결 대기
