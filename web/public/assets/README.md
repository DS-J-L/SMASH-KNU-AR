# 게임 에셋

전체 캠퍼스 실험 모델은 [`campus/`](./campus/README.md)에 있습니다. 단일 건물·파편 GLB와 소리는 아직 없으며 T04에서 `buildings/`와 `audio/`를 추가합니다.

| 예정 파일 | 내용 | 담당 |
| --- | --- | --- |
| `buildings/building-01.glb` | 정상 건물 1개 | 이동수 |
| `buildings/building-01-fragments.glb` | 사전 분할 파편 | 이동수·김태이 |
| `buildings/building-01.json` | 원점·배율·충돌 범위·파편 설정 | 이동수·김태이 |
| `audio/hit.*`, `audio/break.*` | 타격·붕괴 소리 | 김태이 |

위 경로는 예정이며 아직 로딩하지 않습니다. 실제 파일 추가 시 작성자·출처 URL·라이선스·수정 내용·크기를 기록합니다. 공개 자료라는 이유만으로 재배포 가능하다고 가정하지 않습니다.
