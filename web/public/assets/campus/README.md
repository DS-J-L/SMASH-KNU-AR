# 경북대학교 대구캠퍼스 모델 v10

- 실행·공유용: [knu-campus-v10.glb](./knu-campus-v10.glb) (약 19.6MB).
- Blender 5.2.3 편집 원본: [knu-campus-v10.blend](../../../../assets/source/knu-campus-v10.blend) (약 5.6MB). 원본 파일은 이번 요청으로 `assets/source`에 명시적으로 포함했다.
- 작성: 이동수 담당 에셋 작업 / Codex. 2026-10-30.

## 범위와 사용

캠퍼스 윤곽, 건물 123개 윤곽, 도로, 일부 수목과 운동시설을 표현한 실험용 시안이다. Blender 원본은 X 동쪽·Y 북쪽·Z 위쪽, GLB는 X 동쪽·Y 위쪽·Z 남쪽이며 1 단위는 1m다. 원점의 위경도는 경도 128.61035, 위도 35.8903이다. 지형 높이는 이 원점의 표고를 기준으로 한 상대 높이다.

건축물대장 높이와 비교 가능한 건물 40개는 모델 최상단을 대장 높이에 근사하도록 수직 비율을 조정했다. 나머지 높이, 평면 치수, 외관·창, 수목의 위치와 크기, 도로의 세부 경사, 건물 기초, 시설의 평탄면은 실측·전수 검증하지 않았다. 본관 윤곽 면적은 대장 건축면적과 차이가 커 추가 확인이 필요하다. 약 30m 간격의 표고자료를 보간한 것으로 도로 턱·계단·기초 높이까지 정확히 나타내지 못한다.

이 에셋은 실제 게임의 단일 건물·충돌체·파편·AR 정합을 확인한 결과물이 아니다. 게임 로드, 실기기 성능 및 물리 충돌은 미검증이다. GLB는 Blender 파일 → 가져오기 → glTF 2.0으로 열 수 있다.

## 확인 결과

Blender 5.2.3에서 장면 및 표본 메시를 확인했다. 40개 높이 보정 그룹과 123개 건물 윤곽을 검사하고 GLB를 다시 가져왔으며, Khronos glTF Validator에서 오류·경고 0건이었다. 지형·건물의 최저 높이 및 일부 기존 미적용 배율 경고는 상대 지형과 기존 배율에 따른 것으로 별도 확인했다.
