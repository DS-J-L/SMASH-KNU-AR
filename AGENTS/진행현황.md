사용자는 **이동수 담당 작업 전체**를 인수했다. 앞선 팀 전체 인수 해석은 2026-11-02 사용자 확인으로 정정했다. 다음 주(11/09~11/15) 목표, 정확한 일자 미지정. 건물·지형 → 충돌체·파편 패키지 → 키보드 데모 순서. 실행 작업 폴더: `SMASH-KNU-AR/`, 로컬 브랜치 `feat/building-fracture-demo`. 기존 담당자의 실제 개발 완료를 새로 추정하지 않는다.


2026-11-02 20:41 KST 범위 정정: 김태이의 충돌/파편 물리/소리와 정경호의 3D 복원 책임은 유지한다. 이동수 인수 범위에서 모델 파편을 세분화하며 공용 키보드 데모와 실제 담당자 작업 완료를 구분한다.

## 2026-11-03 최신 일정

실제 장비 시험은 **11-09(월), Asia/Seoul**로 사용자 확인. 이동수의 구현·인계 준비 목표는 **이번 주 11-08까지**이며 앞선 11-09~11-15 목표를 정정한다. 시험 시각·장소·실제 장비 목록, 김태이/정경호의 준비 가능일은 미기록이다. 사전 연결 검증과 실기기 결과를 구분하고, 월요일에는 폰 입력 → C0 영상 → 보정/3D 정합 → 준비된 경우 타격·게임 순으로 확인한다. 개인·공통 Phase 완료 상태는 변경하지 않는다.
