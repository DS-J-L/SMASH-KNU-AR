이 표의 `완료`는 PM 계획의 통합 기준을 충족한 기록이 있을 때만 쓴다. 날짜 경과나 개인 작업 완료로 자동 변경하지 않는다. 일정 변경 시 PM 계획·개인 계획과 함께 맞춘다.

| 작업 | 상태 | 근거 | 다음 행동 |

- [ ] 각자 작업 종료 때 개인 기록과 자기 현황 행이 갱신되는지 확인한다.
- [ ] Phase 통합 시 PM 기록의 시나리오·기대/실제 결과·통과 근거를 남긴다.
