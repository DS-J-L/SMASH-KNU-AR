# 캠퍼스 보완 파이프라인 입력

- `campus-elevation-v10.json`: 2026-10-30 v10에서 확보한 FABDEM V1-2 기반 캠퍼스 상대 표고 격자·윤곽·삼각형. 원자료는 약 30m 격자이며 10m 메시 샘플은 보간이다.
- `campus-map-v9.json`: 기존 개선본의 OSM 기반 건물·도로·영역·캠퍼스 윤곽과 출처 기록. 체육시설 평탄면 경계에 사용한다.

새로운 현장 측량·정밀 DEM이 아니다. 파일 내부의 출처와 한계를 보존했다. [모델 출처·이용 조건](../../web/public/assets/campus/README.md) 및 [보완·재생성 방법](../../docs/ASSET_PIPELINE.md)을 따른다. FABDEM V1-2의 CC BY-NC-SA 4.0, © OpenStreetMap 기여자·ODbL 및 기존 자료의 출처 표시를 보존한다.
